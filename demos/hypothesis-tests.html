Hypothesis Tests

Test a claim the way the book does, in four steps: the hypotheses, the distribution, the p value, and the decision with a conclusion in words. The p value is the shaded tail of the null distribution beyond your sample's statistic. Then run a thousand studies at once and count how often the test is wrong: Type I errors when the null hypothesis is true, Type II errors and power when it is false.

Play runs many studies like yours, each with new simulated data, and tallies the decisions.

How it works

Each sample is drawn by the demo from a normal distribution with the true value and spread on the sliders (a proportion: each trial is a success with the true probability). The draws are seeded: Draw 1 is the same on every computer, and New draw moves to the next set. Play runs studies from their own seeded stream, so the same settings give the same tally.

The statistics follow the book. One mean with σ known: z = (x̄ − μ₀)/(σ/√n). With σ unknown: t = (x̄ − μ₀)/(s/√n), df = n − 1. One proportion: z = (p′ − p₀)/√(p₀q₀/n), the normal approximation, fair when np₀ and nq₀ are both more than 5. Two means with σ known: z = (x̄₁ − x̄₂)/√(σ₁²/n₁ + σ₂²/n₂). Unknown: the unpooled t = (x̄₁ − x̄₂)/√(s₁²/n₁ + s₂²/n₂), with Welch's df from the samples. Two proportions: the pooled proportion. Matched pairs: a one sample t test on the differences.

Decision: reject H₀ when the p value is less than α. Over many studies with H₀ true, the fraction rejected is the Type I error rate, close to α; with H₀ false it is the power, 1 − β, and the rest are Type II errors. The fraction from N studies has a standard error √(f(1 − f)/N).

The theory power curve is exact for the z tests (a normal statistic). For one sample and matched pairs t tests it is the noncentral t, worked out by numerical integration. For proportions it uses the normal approximation, and for two means with σ unknown it treats Welch's statistic as a t with the df the true spreads give: both are approximations, so the simulated dots can sit a little off the curve.
