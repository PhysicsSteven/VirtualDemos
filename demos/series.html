What you can type
  • Use n for the index: 1/n^2, (-1)^n/(2n+1), n/2^n.
  • n! or (2n)! for factorials; + − * / ^ and parentheses; 2n and 3sin(n) multiply.
  • sin cos tan, exp or e^n, ln, log (base 10), sqrt, abs or |n|, pi
  • The first index, from n =, is a whole number from 0 to 1,000.
How it works

The box is read by a small parser (demos/lib/vdmath.js); nothing you type is run as code. The partial sums S_N = a(n₀) + … + a(N) are added in double precision with compensated (Kahan) summation, up to N = 1,000,000.

For a setup the sum S is the closed form named in the readout. For a series you type, the demo applies the tests in this order and says which one decided: the divergence test (the largest |a(n)| near n = 10⁹ and 10¹² is not shrinking), the ratio test (|a(n+1)/a(n)| at the largest n whose terms are still normal numbers, extrapolated as 2ρ(n) − ρ(n/2)), the alternating series test (signs alternate and |a(n)| falls), then the integral test on ∫ a(x) dx out to x = 10³⁰⁰. Sums found by the ratio test are added directly; alternating sums are accelerated (Cohen, Rodriguez Villegas and Zagier, 2000); sums by the integral test add 1,000 terms and the Euler–Maclaurin tail. When no test decides, the readout says so.

A sequence's limit is read from short windows of terms at n = 10⁴, 10⁶ and 10⁸; it is given when the windows agree to about 10⁻⁵. N(ε) is checked term by term up to n = 1,000,000.
