Linear Density of a String

A string runs from a vibrator over a pulley to a hanging mass. Hang masses at a fixed frequency, or sweep the frequency with a fixed mass, find the resonances and count the loops. A straight line through your readings gives the string's mass per metre, μ.

More about this

Record stores L, m, T, f and the number of loops n (you can correct n in the table). f against n at one mass: slope v/2L, so μ = T/(4L² · slope²). T against 1/n² at one frequency: slope 4L²f²μ, so μ = slope/(4L²f²). Both lines should pass close to the origin.
